# Measurement — separate artifact quality from behavioral causality

Load this reference only when real analytics, experiments, user behavior, CRO work, or post-launch outcome evidence is in scope.

Do not make every landing-page task a measurement project.

## Evidence boundary

Artifact evaluation can establish:
- truthfulness;
- communication clarity;
- usability/task integrity;
- visual/design quality;
- implementation/runtime quality.

Behavioral measurement can establish:
- what real visitors did in the observed population/time window.

Appropriate controlled evidence is required to establish:
- whether a page change caused a business outcome.

A beautiful page is not proof of conversion lift. A conversion correlation is not automatically proof that a particular design decision caused it.

## Operating model

OBSERVED BEHAVIOR
→ PROBLEM HYPOTHESIS
→ DISCRIMINATING EVIDENCE
→ PAGE INTERVENTION
→ REAL OBSERVATION / EXPERIMENT
→ CAUSAL CONCLUSION ONLY WHEN JUSTIFIED

Keep observation separate from explanation.

## Use existing signals first

Prefer available first-party evidence:
- funnel/CTA completion;
- destination success;
- scroll/engagement only when relevant to a concrete hypothesis;
- form errors/drop-off;
- device segmentation;
- qualitative research;
- experiment data;
- support/sales feedback tied to the page decision.

Do not collect metrics merely because they exist.

## Hypothesis discipline

A useful hypothesis states:
- observed problem;
- plausible cause;
- page decision that would change if the cause is true;
- evidence that could distinguish that cause from alternatives.

If multiple causes fit the same behavior, do not redesign around the most convenient story.

## Experiments

When controlled testing is appropriate:
- preserve truthful variants;
- change enough to discriminate the hypothesis without mixing unrelated variables unnecessarily;
- define the primary outcome before reading results;
- inspect guardrails/material side effects;
- account for sample, duration, segment, and instrumentation limitations;
- report uncertainty rather than manufacturing certainty.

Do not claim universal behavior from a narrow population/time period.

## Creative quality remains independent

Short-term behavioral data can reveal friction or mismatch. It does not by itself define high-end visual quality.

Likewise, a creative-ceiling review can identify a stronger artifact but cannot claim business uplift without behavioral evidence.

Use both when both questions matter.
